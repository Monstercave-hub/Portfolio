Summary
차트에 가려진 게임을 찾고, 위험한 앱은 걸러내는 게임 발견 서비스를 0→1로 설계·구현

스토어는 상위 100~200개의 유명 게임만 반복해서 보여주고, 그 바깥의 게임은 사실상 찾을 방법이 없습니다.

순위에 밀렸다는 이유만으로 좋은 게임이 묻히는 것이 아쉬워, 모든 게임을 볼 수 있는 창구를 만들자는 생각에서 출발했습니다.

구글과 애플 스토어를 양방향으로 수집해 리뷰·설치 수가 적어 노출되지 않던 게임까지 목록에 올렸고,

발견ㆍ신규ㆍ인디ㆍ추천으로 구조를 나눠 원하는 방식대로 찾아볼 수 있도록 설계했습니다.

공식 IP 라이선스가 확인되지 않거나 개인정보를 과도하게 수집하는 앱은 ‘사용자 주의’로 분리해 설치 전에 알 수 있게 했습니다.

기획부터 디자인ㆍ개발ㆍ배포까지 전 과정을 Claude Code 바이브 코딩으로 다루며 실서비스가 가능한 수준까지 경험을 쌓았고,

현재 storedex.kr로 실제 운영 중입니다.

Pain Points & Approach

  • Pain Points
  • Approach
  • 스토어 상위 100~200개가 거의 고정이라, 그 바깥의 게임은 존재 자체를 알기 어려움.
  • 리뷰·설치 수가 적어 노출되지 않던 게임만 모은 ‘발견’을 게임 메뉴의 기본 진입점으로 두고, ‘인디’ㆍ‘전체’로 탐색 범위를 넓힐 수 있도록 구성.
  • 제목을 정확히 알아야 검색되기 때문에, 이름을 모르면 찾을 방법이 없음.
  • 약칭ㆍ다른 표기로도 같은 게임에 닿도록 검색 별칭을 두고, 검색과 카테고리 탐색을 함께 제공해 이름을 몰라도 찾아갈 수 있도록 설계.
  • 신작 출시일이 흩어져 있고, 사전예약과 정식 출시가 섞여 지금 할 수 있는 게임인지 헷갈림.
  • 출시 60일 내 게임을 ‘신규’로 분리하고 ‘사전예약’ㆍ‘출시 캘린더’를 별도 메뉴로 두어, 지금 할 게임과 기다릴 게임을 구분.
  • 광고와 실제 게임이 달라, 설치하고 실행해본 뒤에야 차이를 알게 됨.
  • 실제 플레이 화면과 스크린샷 유사도를 AI로 자동 분석. 사용자가 직접 판단할 수 있도록 제작.
  • 공식 IP 라이선스나 개인정보 처리방침을 확인할 수 없는 앱이 목록에 섞여 있음.
  • IP 라이선스 미확인ㆍ개인정보 과다 수집 등 5개 기준으로 ‘사용자 주의’ 메뉴에 분리하고, 상세 화면에 주의 사유를 함께 노출.
  • 운영자 혼자서는 문제가 있는 앱이나 누락된 게임을 모두 파악할 수 없음.
  • ‘제보하기’로 이용자가 직접 알릴 수 있게 하고, ‘내 제보’에서 처리 상태를 확인할 수 있도록 연결.
  • 관심 가는 게임을 찾아도 나중에 다시 찾아오기 어려움.
  • ‘찜한 게임’으로 모아 두고, ‘소식’에서 이벤트ㆍ사전예약ㆍ게임 영상 등 후속 정보를 이어볼 수 있도록 구성.
IA & User Flow
찾는 목적에 따라 게임을 나누고, 로그인 없이도 탐색이 끝나도록 구조화

게임을 발견ㆍ신규ㆍ추천ㆍ인디ㆍ전체ㆍ사용자 주의 여섯 갈래로 나눠, 찾는 목적에 따라 한 번의 이동으로 원하는 목록에 닿도록 구성했으며,

사전예약ㆍ출시 캘린더ㆍ소식을 게임과 같은 깊이에 두어, 지금 할 게임과 기다리는 게임을 오가며 볼 수 있게 했습니다.

로그인은 찜한 게임ㆍ내 제보ㆍ계정 설정 같은 개인 기능에만 요구하고, 탐색과 제보는 로그인 없이 끝나도록 흐름을 분리했습니다.

01. Main Page

숨겨진 게임을 찾아주고 출시 예정 게임까지 한번에 확인 가능한 서비스로

플랫폼ㆍ장르ㆍ가격ㆍ평점으로 좁혀가며 볼 수 있도록 설계했습니다.

02. AI 분석

등록된 스크린샷과 실제 플레이 화면을 AI 분석을 통해 그래픽 수준을 비교합니다.

허위/과장된 스크린샷과 실제 화면을 설치 전 사용자가 확인하여

불필요한 설치를 줄여줍니다.

03. 발견

스토어 순위에 가려저 보이지 않는 게임들을 모아 놓은 페이지로

마케팅, 홍보 등을 못해 잊혀질 수 있는 좋은 게임들을 발견할 수 있는 공간입니다.

사용자에겐 새로운 게임을, 작은 개발사에겐 노출의 기회를 제공합니다.

04. 사용자 주의

개인정보 처리 방침에 문제가 있거나 IP 도용 게임 등을 AI 분석을 통해

사유와 실제 스크린샷을 보여주고, 사용자에게 설치 전 주의할 수 있도록 안내하여

위험 요소를 사전에 방지합니다.

공식 IP 확인 불가, 허위 광고, 개인정보 과다 수집 등이 확인된 게임 목록입니다. 설치 전 개인정보 처리 방침을 직접 확인하시기 바라며, 과금과 개인정보 제공에 유의하시기 바랍니다.
05. 어드민

StoreDex의 회원/앱/배너 등을 관리할 수 있는 어드민 페이지로

크롤러의 경우 단순히 스토어에서 내려주는 데이터만이 아닌

키워드, 역방향 조회, 스토어 순위 매칭 후 데이터 분리등을 통해

보다 다양하고 정확한 데이터를 수집하고 있습니다.

  • 전체 수집외에 사전예약, 플랫폼 매칭, 상세정보 보강 등의 다양한 크롤링 옵션
  • 각 게임의 정보, 공식 커뮤니티, AI 분석 등을 제어할 수 있는 앱 수동관리 메뉴
  • Supabase, Google, Kakao를 통한 회원 관리
  • 구좌별 간편한 노출 제어 옵션의 광고 관리
Mobile Screens

반응형 디자인/퍼블리싱으로 다양한 디바이스 환경에 유연하게 대응하며

일관된 사용자 경험과 흐름이 유지되도록 제작하였습니다.

Design Outcomes
스토어가 보여주지 않던 게임을 찾아 분류하고, 혼자서도 운영되는 서비스로 완성

화면 설계에서 끝내지 않고 수집ㆍ검수ㆍ운영 도구까지 직접 만들어,

디자이너 한 사람이 실제 서비스를 유지할 수 있는 구조로 정리했습니다.

탐색 구조 설계
  • 게임을 발견ㆍ신규ㆍ추천ㆍ인디ㆍ전체ㆍ사용자 주의 여섯 갈래로 나눠, 찾는 목적에 따라 한 번의 이동으로 원하는 목록에 닿도록 설계
  • 수집한 2만 3천여 개 중 1만 4천여 개를 ‘발견’으로 분류해, 차트에 노출되지 않던 게임을 서비스의 기본 진입점으로 삼음
수집 자동화 & 데이터 품질
  • 구글ㆍ애플 스토어를 양방향으로 수집하고 역방향 보강으로 누락을 메우는 파이프라인을 구성
  • 연령고지ㆍ공유 아이콘이 섞인 스크린샷을 걸러내고 출시앱과 사전예약을 분리해, 목록 자체의 신뢰도를 확보
이용자 보호 장치
  • IP 라이선스 미확인ㆍ개인정보 과다 수집 등 5개 기준으로 ‘사용자 주의’를 분리하고, 상세 화면에 주의 사유를 함께 노출
  • 제보는 로그인 없이 받고, 로그인하면 마이페이지에서 처리 상태를 확인할 수 있도록 연결
1인 운영 구조
  • 수집ㆍ검수ㆍ추천ㆍ배너ㆍ소식ㆍ제보ㆍ회원 관리를 어드민 하나로 묶어, 운영자 한 명이 서비스를 유지할 수 있도록 구성
  • 정적 빌드 후 배포하는 구조에 sitemapㆍRSSㆍ구조화 데이터를 더해 검색 노출과 응답 속도를 함께 확보
