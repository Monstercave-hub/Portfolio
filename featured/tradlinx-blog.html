Summary
마케팅과 SEO를 위한 검색 최적화 블로그 제작

SEO에 강한 워드프레스로 제작, 기능적 요구 사항이 최대한 들어있으며 가벼운 테마를 선택.

테마의 기능 중, 필요한 기능과 불필요한 기능을 구분하여 코드를 정리하고

기능적 추가 요구 사항을 제작함과 동시에 디자인을 변경.

Theme 선택
요구사항 반영이 빠른 경량 테마로 제작 속도를 확보

빠른 구축이 우선인 상황에서, 요구사항 적용이 쉬운 테마를 선택했습니다.

무거운 기능은 최소화하고 운영 효율을 중심으로 구성했습니다.

Requirements

  • 트레드링스 사이트 안에서 이동하는 느낌이었으면 좋겠어요.

    GNB·Footer, 폰트 크기와 컬러를 트레드링스 사이트 기준으로 동일하게 적용.

  • 중요한 내용이 한눈에 보이게 큰 배너가 있었으면 좋겠어요.

    첫 화면 상단에 배너 영역을 배치하고, 텍스트/배경만 교체해 바로 홍보할 수 있게 구성.

  • 검색창은 좀 더 크게 넣어주세요.

    배너 바로 아래에 가로 폭을 넓게 확보해 검색 영역을 우선 배치

  • 게시글에는 사진과 카테고리, 제목, 내용 일부, Tag와 날짜가 함께 보였으면 해요.

    요구 사항을 순서대로 배치, 10개의 게시글 리스트가 나온 후 페이징 처리.

  • 해당 영역에서 요구한 메뉴 리스트.

    Tag, 뉴스레터 구독 기능은 따로 제작, 워드프레스 기능을 활용해 별도 개발 없이 구성.

유입과 이동
홈페이지 메인에서 최신 콘텐츠 바로 노출

트레드링스 홈페이지 메인에 블로그 최신 글을 연동해

필요한 정보를 빠르게 확인하고, 블로그와 홈페이지를 자연스럽게 오갈 수 있도록 구성하여

검색 유입 이후에도 서비스로 이어지는 접점을 강화했습니다.

Mobile Screens

두 사이트간의 자연스러운 유입과 이동을 유도하였습니다.

Design Outcomes
개발 리소스 없이도 운영이 성장하는 SEO 채널을 구축

마케팅팀이 직접 콘텐츠를 발행·수정할 수 있도록 운영 구조를 정리하고,

검색 유입과 홈페이지 전환 흐름이 자연스럽게 연결되도록 개선

SEO 유입 기반 강화
  • 구글 검색 노출이 개선되어 콘텐츠 유입이 실제로 발생
  • 키워드/콘텐츠 누적이 가능한 구조로 채널 기반을 확보
운영 자율성 확보(마케팅팀 중심)
  • 개발팀 도움 없이 게시글·배너 등 운영이 가능하도록 구성
  • 운영 속도를 높여 캠페인 대응이 더 빠르게 진행됨
플러그인 기반 확장 구조
  • 필요한 기능을 플러그인으로 해결해 추가 개발을 최소화
  • 요구사항 변경에도 빠르게 대응할 수 있는 운영 환경 구축
홈페이지 전환 흐름 개선
  • 블로그와 홈페이지의 톤앤매너를 맞춰 이질감을 줄임
  • 콘텐츠 → 서비스 페이지로 이어지는 유입 동선을 강화
